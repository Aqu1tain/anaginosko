## Une forme de référence

En grec, un même mot prend de nombreuses formes : λόγος, λόγου, λόγῳ, λόγον, λόγοι… Un dictionnaire ne peut pas toutes les enregistrer. Il les range sous une forme unique, le **lemme** :

- pour un nom, le **nominatif singulier** : λόγος ;
- pour un adjectif, le **nominatif masculin singulier** : ἀγαθός ;
- pour un verbe, la **1re personne du singulier du présent de l'indicatif actif** : λύω, « je délie ».

Les mots invariables (adverbes, prépositions, conjonctions, particules) apparaissent tels quels dans le texte et dans le dictionnaire.

| Nature | Lemme | Forme de référence |
| --- | --- | --- |
| Nom | λόγος | nominatif masculin singulier |
| Adjectif | ἀγαθός | nominatif masculin singulier |
| Verbe | λύω | 1re pers. sing., présent, indicatif, actif |
| Pronom | αὐτός | nominatif masculin singulier |
| Article | ὁ | nominatif masculin singulier |
| Adverbe | νῦν | invariable |
| Préposition | ἐν | invariable |
| Conjonction | καί | invariable |
| Particule | οὖν | invariable |
| Interjection | ἰδού | invariable |

## Pourquoi c'est essentiel

Savoir retrouver un lemme, c'est devenir autonome. Un étudiant qui connaît beaucoup de règles mais ne sait pas remonter au lemme reste dépendant des traductions. Celui qui l'identifie vite peut ouvrir n'importe quel dictionnaire ou concordance, car ces outils sont presque toujours organisés par lemmes.

Sur Anaginosko, chaque mot du texte affiche son lemme, et chaque lemme a sa fiche dans la [concordance](/concordance), avec toutes ses occurrences. Essayez avec [λόγος](/concordance/λόγος).
