L'une des formes verbales les plus fréquentes du Nouveau Testament est εἶπεν, « il dit » : près de six cents occurrences. Ouvrez un dictionnaire à la lettre ε : il n'y est pas. Pour le trouver, il faut chercher… λέγω. Bienvenue dans le monde des **formes** et des **lemmes**, la compétence qui vous rendra autonome.

## Un mot, beaucoup de formes

En français, un verbe change déjà de forme : *je dis*, *nous disons*, *il dit*, *ils dirent*. Mais un dictionnaire ne donne qu'une seule entrée, *dire*. Cette forme de référence s'appelle le **lemme**.

Le grec pousse la logique beaucoup plus loin : les noms, les adjectifs, les pronoms et l'article changent eux aussi de forme selon leur rôle dans la phrase. Dans le Nouveau Testament, le nom λόγος apparaît sous huit formes : λόγος, λόγου, λόγῳ, λόγον, λόγοι, λόγων, λόγοις, λόγους. Le verbe γίνομαι, « devenir », se présente sous près de quatre-vingts formes différentes. Aucun dictionnaire ne peut toutes les enregistrer.

::exercice Sous quelle entrée un dictionnaire range-t-il la forme λόγου ?
+ λόγος
- λόγου
- λόγον
= Toutes les formes d'un nom sont rangées sous une seule : le nominatif singulier, ici λόγος.

## Les règles du lemme

Le lemme obéit à des conventions simples :

- pour un **nom**, c'est la forme du sujet au singulier (on l'appelle le *nominatif singulier*) : λόγος, « parole » ;
- pour un **adjectif**, c'est la même forme, au masculin : ἀγαθός, « bon » ;
- pour un **verbe**, c'est la première personne du singulier du présent : λύω, « je délie ». Les dictionnaires français le traduisent par un infinitif : λύω, « délier ».

Les mots **invariables** ne changent jamais : adverbes (νῦν, « maintenant »), prépositions (ἐν, « dans »), conjonctions (καί, « et »), particules (οὖν, « donc »), interjections (ἰδού, « voici »). Ils apparaissent dans le texte exactement sous leur forme de dictionnaire.

| Nature du mot | Exemple de lemme | Forme de référence |
| --- | --- | --- |
| Nom | λόγος | nominatif singulier |
| Adjectif | ἀγαθός | nominatif masculin singulier |
| Pronom | αὐτός | nominatif masculin singulier |
| Article | ὁ | nominatif masculin singulier |
| Verbe | λύω | 1re personne du singulier, présent |
| Mot invariable | καί, ἐν, νῦν | toujours identique |

> **Piège classique.** Certains verbes n'existent qu'avec la terminaison -ομαι : leur lemme se termine alors en -ομαι, comme γίνομαι, « devenir ». Ne cherchez pas un γίνω : il n'existe pas.

::exercice Lequel de ces mots apparaît dans le texte exactement sous sa forme de dictionnaire ?
- θεοῦ
- ἦν
+ καί
= καί est une conjonction, donc invariable. θεοῦ est une forme de θεός, et ἦν une forme du verbe εἰμί, « être ».

::exercice Dans Jean 1,1, on lit ἦν, « était ». Sous quel lemme le chercher ?
- ἦν
+ εἰμί
- ἐστί
= Le lemme d'un verbe est la 1re personne du présent : εἰμί, « je suis ». ἦν (« il était ») et ἐστί (« il est ») en sont des formes.

## Lire une entrée de dictionnaire

Pour un nom, le dictionnaire donne trois informations, toujours dans le même ordre : le lemme, une terminaison, et l'article. Par exemple :

> λόγος, ου, ὁ : parole, discours.

Le *ου* est la terminaison du génitif, une autre forme du mot (λόγου) qui sert à le ranger dans sa famille ; vous la découvrirez bientôt. L'article ὁ indique le **genre** : ὁ pour le masculin, ἡ pour le féminin, τό pour le neutre.

::exercice Le dictionnaire donne : χάρις, ιτος, ἡ, « grâce ». De quel genre est ce mot ?
- masculin
+ féminin
- neutre
= L'article ἡ marque le féminin. En grec comme en français, le genre des choses est souvent arbitraire : φῶς, « la lumière », est neutre.

## Les outils du lecteur

Personne ne lit le grec biblique sans outils. L'enjeu n'est pas de retenir tous les tableaux, mais de savoir **remonter au lemme**, puis trouver le sens.

- **Sur Anaginosko** : touchez un mot dans un chapitre pour obtenir son lemme, son analyse, sa prononciation et la notice du dictionnaire Bailly ; chaque lemme a sa fiche dans la [concordance](/concordance), avec toutes ses occurrences.
- **Un lemmatiseur** comme Eulexis (Biblissima) fonctionne dans les deux sens : on lui donne une forme du texte, il retrouve le lemme ; on lui donne un lemme, il donne la définition.
- **Les dictionnaires** : le Bailly (grec-français), le LSJ (grec-anglais), le BDAG (spécialisé dans le Nouveau Testament).
- **Les grammaires** : Ragon, Joëlle Bertrand, ou celle de Carrez, conçue pour le grec du Nouveau Testament.
- **Les Bibles imprimées** : le Nouveau Testament de Nestle-Aland, ou une Bible interlinéaire grec-français.

::exercice Dans Jean 1,7, Jean-Baptiste vient « rendre témoignage à la lumière » : περὶ τοῦ φωτός. Quel est le lemme de φωτός ?
= φῶς, « lumière ». Le nom se transforme beaucoup (φωτός, φωτί…), mais le dictionnaire le range sous φῶς. Vous avez rencontré φωτός dans *photographie*.

## Mission

Voici un verset de douze mots. Touchez chacun d'eux pour afficher son lemme.

::verset nt jn 1 4

::exercice Douze mots dans ce verset. Combien de lemmes différents ?
- Douze
- Dix
+ Huit
= ἐν, αὐτός (pour αὐτῷ), ζωή (deux fois), εἰμί (pour les deux ἦν), καί, ὁ (pour ἡ, τὸ et τῶν), φῶς et ἄνθρωπος (pour ἀνθρώπων). L'article ὁ prend à lui seul trois formes dans ce verset.

::exercice Quel est le lemme de ἀνθρώπων, et quel mot français en est issu ?
= ἄνθρωπος, « être humain ». Il a donné *anthropologie*, l'étude de l'homme, et *philanthrope*, l'ami des hommes.

## À retenir

- Le **lemme** est la forme sous laquelle un mot est rangé dans le dictionnaire.
- Nom : nominatif singulier (λόγος) ; adjectif : nominatif masculin singulier (ἀγαθός) ; verbe : 1re personne du présent (λύω).
- Les mots invariables (καί, ἐν, νῦν) sont identiques dans le texte et dans le dictionnaire.
- Une entrée de nom donne lemme, terminaison du génitif et article : λόγος, ου, ὁ.
