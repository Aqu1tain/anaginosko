## La méthode

Pour chaque passage : repérez le verbe principal, le sujet au nominatif, puis les compléments. Utilisez le vocabulaire fourni, et le lecteur d'Anaginosko pour analyser chaque mot. Comparez enfin votre traduction aux deux traductions proposées : elles montrent qu'il n'existe pas une seule bonne réponse.

## 1. Romains 15, 1

::verset nt ro 15 1-1

| Mot | Sens |
| --- | --- |
| ὀφείλω | devoir, être obligé de |
| δυνατός, ή, όν | fort, puissant, capable |
| ἀσθένημα, ατος, τό | faiblesse |
| ἀδύνατος, ον | faible, incapable |
| βαστάζω | porter, supporter (βαστάζειν, infinitif) |
| μή | ne… pas |
| ἑαυτοῦ | de soi-même, soi-même |
| ἀρέσκω | plaire (ἀρέσκειν, infinitif) |

Deux traductions :

- « Nous qui sommes forts, nous devons supporter les faiblesses de ceux qui ne le sont pas, et ne pas nous complaire en nous-mêmes. »
- « Nous, les forts, nous devons porter la fragilité des faibles, et non pas faire ce qui nous plaît. »

## 2. Romains 15, 8

::verset nt ro 15 8-8

| Mot | Sens |
| --- | --- |
| λέγω | dire ; avec un infinitif : « je dis que » |
| γάρ | car, en effet |
| διάκονος, ου, ὁ | serviteur |
| γεγενῆσθαι | infinitif parfait de γίνομαι, « être devenu » |
| περιτομή, ῆς, ἡ | circoncision |
| ὑπέρ + génitif | pour, en faveur de |
| εἰς τό + infinitif | pour, afin de |
| βεβαιόω | confirmer, affermir |
| ἐπαγγελία, ας, ἡ | promesse |

Deux traductions :

- « Je dis, en effet, que le Christ a été serviteur des circoncis, pour prouver la véracité de Dieu en confirmant les promesses faites aux pères. »
- « Car je vous le déclare : le Christ s'est fait le serviteur des Juifs, en raison de la fidélité de Dieu, pour réaliser les promesses faites à nos pères. »

## 3. Jean 15, 1-2

::verset nt jn 15 1-2

| Mot | Sens |
| --- | --- |
| ἄμπελος, ου, ἡ | vigne |
| ἀληθινός, ή, όν | vrai, véritable |
| γεωργός, οῦ, ὁ | cultivateur, vigneron |
| κλῆμα, ατος, τό | sarment |
| φέρω | porter (φέρον, participe neutre) |
| καρπός, οῦ, ὁ | fruit |
| αἴρω | enlever |
| καθαίρω | purifier, émonder |
| ἵνα + subjonctif | afin que |
| πλείων, ον | plus abondant |

Deux traductions :

- « Moi, je suis la vraie vigne, et mon Père est le vigneron. Tout sarment qui est en moi, mais qui ne porte pas de fruit, mon Père l'enlève ; tout sarment qui porte du fruit, il le purifie en le taillant, pour qu'il en porte davantage. »
- « Je suis le vrai cep, et mon Père est le vigneron. Tout sarment qui est en moi et qui ne porte pas de fruit, il le retranche ; et tout sarment qui porte du fruit, il l'émonde, afin qu'il porte encore plus de fruit. »

## 4. Matthieu 16, 2-3

::verset nt mt 16 2-3

| Mot | Sens |
| --- | --- |
| ἀποκρίνομαι | répondre (ἀποκριθείς, participe aoriste) |
| ὀψία, ας, ἡ | le soir |
| εὐδία, ας, ἡ | beau temps |
| πυρράζω | être rouge feu |
| πρωΐ | le matin |
| σήμερον | aujourd'hui |
| χειμών, ῶνος, ὁ | tempête, mauvais temps |
| στυγνάζω | être sombre, menaçant |
| πρόσωπον, ου, τό | visage, aspect |
| διακρίνω | discerner |
| σημεῖον, ου, τό | signe |
| καιρός, οῦ, ὁ | moment, temps |
| δύναμαι | pouvoir |

Deux traductions :

- « Jésus leur répondit : Le soir, vous dites : Il fera beau, car le ciel est rouge ; et le matin : Il y aura de l'orage aujourd'hui, car le ciel est d'un rouge sombre. Vous savez discerner l'aspect du ciel, et vous ne pouvez discerner les signes des temps. »
- « Il leur répondit : Quand vient le soir, vous dites : Voici le beau temps, car le ciel est rouge. Et le matin, vous dites : Aujourd'hui, il fera mauvais, car le ciel est d'un rouge menaçant. Ainsi l'aspect du ciel, vous savez en juger ; mais pour les signes des temps, vous n'en êtes pas capables. »

Remarquez ὀψίας γενομένης au verset 2 : un génitif absolu, vu dans la leçon précédente.
