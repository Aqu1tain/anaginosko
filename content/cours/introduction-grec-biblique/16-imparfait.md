## Une action passée vue dans sa durée

L'imparfait se construit sur le **thème du présent**. Il décrit une action passée en cours, habituelle ou répétée : « je déliais ».

## L'augment

Comme tous les temps secondaires, l'imparfait prend un **augment** :

- devant une consonne, on ajoute ἐ- : λύω, ἔλυον ;
- devant une voyelle, celle-ci s'allonge : ἀκούω, ἤκουον ;
- dans un verbe composé, l'augment se place entre le préfixe et le verbe : ἐκβάλλω, ἐξέβαλλον.

## Les formes

| Personne | Actif | Moyen-passif |
| --- | --- | --- |
| 1re sing. | ἔλυον, je déliais | ἐλυόμην, j'étais délié |
| 2e sing. | ἔλυες | ἐλύου |
| 3e sing. | ἔλυε(ν) | ἐλύετο |
| 1re plur. | ἐλύομεν | ἐλυόμεθα |
| 2e plur. | ἐλύετε | ἐλύεσθε |
| 3e plur. | ἔλυον | ἐλύοντο |

La 1re personne du singulier et la 3e du pluriel sont identiques (ἔλυον) : seul le contexte permet de choisir.

## L'imparfait de εἰμί

| Personne | Forme | Traduction |
| --- | --- | --- |
| 1re sing. | ἦν | j'étais |
| 2e sing. | ἦσθα | tu étais |
| 3e sing. | ἦν | il, elle était |
| 1re plur. | ἦμεν | nous étions |
| 2e plur. | ἦτε | vous étiez |
| 3e plur. | ἦσαν | ils, elles étaient |

C'est le ἦν du prologue de Jean : ἐν ἀρχῇ ἦν ὁ λόγος, « au commencement était la Parole ».

## Exercice

Traduisez :

1. ὁ μαθητὴς ἔγραφε τὸν λόγον.
2. οἱ ἵπποι ἐλύοντο ὑπὸ τῶν μαθητῶν.
3. ἐγὼ ἔπεμπον τὸν φίλον εἰς τὴν οἰκίαν.
4. οἱ μαθηταὶ ἐν τῇ οἰκίᾳ ἦσαν.
5. οἱ μαθηταὶ ἔβλεπον τὸν διδάσκαλον.

## Corrigé

1. Le disciple écrivait le discours.
2. Les chevaux étaient déliés par les disciples.
3. J'envoyais l'ami à la maison.
4. Les disciples étaient dans la maison.
5. Les disciples regardaient le maître.
