## L'action vue comme un tout

L'aoriste présente l'action **dans son ensemble**, sans insister sur sa durée. C'est le temps ordinaire du récit. Selon le contexte, il exprime :

- **une action ponctuelle** : « il frappa » ;
- **une action passée vue globalement**, même longue : « il régna dix ans » ;
- **une succession d'actions** : « il entra, vit son ami et parla » ;
- **l'entrée dans un état** : « il devint roi ».

À l'indicatif, il se traduit le plus souvent par un passé simple ou un passé composé.

## L'aoriste sigmatique

C'est la forme la plus courante : augment, radical, puis **-σα** et ses terminaisons.

| Personne | Forme | Traduction |
| --- | --- | --- |
| 1re sing. | ἔλυσα | je déliai |
| 2e sing. | ἔλυσας | tu délias |
| 3e sing. | ἔλυσε(ν) | il, elle délia |
| 1re plur. | ἐλύσαμεν | nous déliâmes |
| 2e plur. | ἐλύσατε | vous déliâtes |
| 3e plur. | ἔλυσαν | ils, elles délièrent |

Le σ se combine avec la consonne qui le précède :

- **π, β, φ + σ = ψ** : πέμπω, ἔπεμψα ; γράφω, ἔγραψα ;
- **κ, γ, χ + σ = ξ** : διώκω (poursuivre), ἐδίωξα ;
- **τ, δ, θ** disparaissent devant σ : πείθω (persuader), ἔπεισα.

Beaucoup de verbes très fréquents ont un **aoriste second**, sans σ, à apprendre avec le verbe : γίνομαι, ἐγενόμην ; λέγω, εἶπον ; ὁράω, εἶδον. Le dictionnaire les donne.

## Exercice

Traduisez :

1. ἔλυσα τὸν δοῦλον.
2. ἔγραψας τὸν λόγον.
3. ὁ μαθητὴς ἔβλεψε τὸν διδάσκαλον.
4. ἐπέμψαμεν τὸ δῶρον.
5. οἱ μαθηταὶ ἔγραψαν τοὺς λόγους.

## Corrigé

1. Je déliai l'esclave (ou : j'ai délié).
2. Tu écrivis le discours.
3. Le disciple regarda le maître.
4. Nous envoyâmes le présent.
5. Les disciples écrivirent les discours.
