Les bibliothèques installées par npm conservent leurs licences respectives. Le
fichier package-lock.json fixe les versions utilisées et les paquets distribués
conservent leurs métadonnées et avis de licence. La licence propriétaire du code
Anaginosko ne modifie pas les droits accordés par ces bibliothèques.
